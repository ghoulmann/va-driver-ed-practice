# Virginia Driver Ed — adaptive practice

A static, offline study app: it draws practice questions adaptively, tracks mastery against the
2022 Virginia Standards of Learning for Driver Education, and estimates your chance of passing a
ten-question quiz that tolerates three misses.

No server, no accounts, no network calls at runtime. Progress lives in your own browser.

## Running it

```bash
python -m http.server 8000   # from the repository root
```

Then open <http://localhost:8000/>.

Opening `index.html` straight off the filesystem will not work — the app fetches its JSON data
files, and browsers block that over `file://`.

Deployed automatically to GitHub Pages by `.github/workflows/pages.yml`.

## Layout

| Path | What it is |
|---|---|
| `js/fsrs.js` | Spaced repetition per item (FSRS-4.5): when a question should come back |
| `js/select.js` | What to ask next: due reviews, then new questions by topic need, then the weakest |
| `js/session.js` | Session lifecycle, scoring, topic mastery rollup, pass-probability estimate |
| `js/store.js` | Profiles in `localStorage`, namespaced `va-driver-ed-practice:v1:`, with export/import and migration |
| `js/ui.js` | The only module that touches the DOM |
| `data/taxonomy.json` | DE.1–DE.24 plus behind-the-wheel skills — generated by `tools/build_taxonomy.py` |
| `data/items.json` | The shipped item bank |
| `research/` | The verification evidence behind every answer |
| `backlog.md` | What is still to be authored, and what is blocked on sourcing |

See [CONTRIBUTING.md](CONTRIBUTING.md) for the full authoring, sourcing, and commit
conventions.

## Authoring an item

An item ships only when `status: "reviewed"` **and** `accuracy.status: "verified"`. Both gates are
enforced by `tests/test_items.py`, along with the rule that no shipped stem may reproduce a
question from the source course verbatim.

```json
{
  "id": "de10a-implied-consent-003",
  "concept": "de10a-implied-consent",
  "sol": ["DE.10a"],
  "region": "va",
  "form": "multiple_choice",
  "stem": "...",
  "options": [{ "id": "a", "text": "...", "rationale": "why this one is wrong" }],
  "answer": "c",
  "explanation": "...",
  "source": { "kind": "reauthored", "basis": "..." },
  "accuracy": {
    "status": "verified",
    "verified_on": "2026-09-01",
    "authority": [{ "cite": "Va. Code § 46.2-861.1",
                    "url": "https://law.lis.virginia.gov/...",
                    "effective": "2023-07-01" }]
  },
  "status": "reviewed"
}
```

Three forms are supported: `multiple_choice`, `true_false`, and `ordering` (which uses `steps`
and `answerOrder` instead of `options`). `concept` names the fact the item tests; items that share
a concept are variants of one another and are never asked in the same session.

**Where current law and the course disagree**, carry both answers: `answer` is what Virginia law
says, `course_answer` is what the course grades as correct, and `divergence` explains the gap. The
app shows both — you need one answer to drive by and one to pass by.

Every legal fact needs a primary source: the Code of Virginia, DMV, VDOT, or Virginia DOE. A
law-firm blog can point you at a change; it can never substantiate one.

## Tests

```bash
python -m venv .venv && . .venv/bin/activate && pip install -r requirements-dev.txt

pytest                # item-bank gates
node tests/run.mjs    # engine assertions, headless
```

`tests/engine.html` runs the same engine suite in a browser.

## Regenerating data

```bash
python tools/build_taxonomy.py   # -> data/taxonomy.json
python tools/build_resources.py  # -> data/resources.json (the credits view's source list)
python tools/build_artifact.py   # -> dist/artifact.html (single-file bundle)
```

`build_resources.py` derives the source list from the authorities the items themselves cite, plus
a curated list of sources consulted that no shipped item happens to cite — including the checks
that confirmed nothing had changed. It also carries the method and the four questions the
verification pass could not settle. A test fails if an item cites an authority the list omits, or
if anything but a primary Virginia source appears in it.
